# Issue #43：长材料理解与信息利用题库设计

版本：`capability-long-context/v1`  
父任务：[#17](https://github.com/relaxcloud-cn/llm-capability-doctor/issues/17)  
上下文边界交接：[#38](https://github.com/relaxcloud-cn/llm-capability-doctor/issues/38)  
实现交接：[#26](https://github.com/relaxcloud-cn/llm-capability-doctor/issues/26)

本文只测材料变长后模型对已给信息的查找、关联、汇总和干扰排除能力。#38 负责上下文容量；本设计不能把长度档位成功改写成容量上限，也不测最长输出、性能或 Agent。

## 1. 基础任务与长度档

共 40 个基础任务，五类各 8 题；每题最多扩展为 4K、16K、64K 三个长度条件，因此最多 120 次观察。长度条件是同一基础题的重复测量，不是 120 个独立题目。

| 类别 | 编号 | 目标 |
| --- | --- | --- |
| 分散事实查找 | L01-L08 | 从材料前、中、后位置查找唯一事实 |
| 跨段关联 | A01-A08 | 关联不同段落的对象和属性 |
| 信息汇总 | S01-S08 | 汇总固定集合，检查遗漏和多报 |
| 干扰排除 | D01-D08 | 排除相似但不相关的干扰记录 |
| 信息缺失识别 | M01-M08 | 材料未提供时明确未知，不编造 |

实际执行前必须取得 #38 的可靠输入范围和计数来源：若某档超过已验证范围，标记 `not_applicable`/`missing`，不强行发送。档位不适用不计为 0 分。

## 2. 材料构造

每个基础任务包含固定头部、事实段、干扰段、问题段和尾部校验标记。只按预先固定规则增加干扰材料或改变目标事实位置；答案事实数量、关系数量、推理步数和问题文本保持不变。

每个长度版本保存：基础题 ID、长度档、材料内容哈希、生成种子、参考 token 数、服务实际 `usage.prompt_tokens`、消息角色、输出预留、语言、模型和输入余量。不同 tokenizer 的同名 token 档不作为严格同题依据；跨服务比较只使用共同实际计数和共同材料。

位置方案固定为前 1/3、中 1/3、后 1/3；不得根据模型输出动态移动事实或删除失败题。干扰内容必须语义中性，不能暗中增加专业知识或额外推理。

## 3. 执行条件

所有长度版本使用同一模型、服务、`temperature=0`、非流式接口和统一回答格式。每个基础题每个可用档位初测 1 次；有效但不完整或错误的回答可追加最多 2 次同条件复核，首次有效失败保留。网络、认证、限流、超时或截断按执行异常重试，最多 2 次；异常不能变成长上下文失败。

长材料检测的安全停止条件：达到服务已验证输入上限、检测到连续环境异常、请求体触及代理限制、或完成全部可用档位。未找到失败边界时只报告最高已验证档，不继续探测 #38 的容量边界。

## 4. 评分与趋势

主指标按“基础题 × 长度档”分别计算完整正确数 / 已评分有效数。字段或事实的遗漏、多报、关系错误、干扰误用和无依据补全单独计数；不按材料长度对分数加权。

| 标签 | 条件 | 处理 |
| --- | --- | --- |
| `correct` | 目标事实/关系/集合完整正确，且满足题目要求 | 进入该档有效分母 |
| `wrong` | 有效回答但遗漏、多报、错连、误用干扰或编造 | 进入该档有效分母 |
| `incomplete` | 输出可解析但缺少必要对象/字段，无法整题通过 | 进入有效分母，单独统计 |
| `pending` | 题目或答案映射无法唯一判断 | 不进入自动正确率 |
| `missing` | 未执行、超范围、执行异常或证据不足 | 不进入有效分母 |

允许等义表达和集合顺序必须在题目中预先声明。各长度档可展示趋势，但不得把档位平均成隐含“长上下文总分”，也不得用短档失败推导容量结论。

## 5. 正反例

固定关系材料：项目 R 的负责人是小周；小周所在团队为 T2；无关项目 Q 的负责人也是小周，但团队为 T9。问题要求回答 R 的团队。

| 回答 | 标签 | 原因 |
| --- | --- | --- |
| `T2` | `correct` | 目标关系正确 |
| `T9` | `wrong` | 把同名无关对象的值串入目标 |
| `无法确定` | `wrong` | 材料已给出完整关系 |
| 材料未给出 R 的团队时回答 `unknown` | `correct` | 正确识别信息缺失 |
| 只回答负责人小周 | `incomplete` | 未回答题目要求的关联结果 |

## 6. 证据与客户展示

证据至少包含材料哈希和长度构造规则、参考/实际 token 计数、输入余量、目标事实位置、原始响应、解析答案、字段级差异、复核/重试关系、档位适用性和停止原因。不得把外部文章、RULER 原题或其榜单阈值直接当产品题库或容量标准。

客户主视图展示每个长度档的“正确／未通过／未完成／未测”和最高已验证档；若无可靠失败边界，明确显示“未测出上限”。详情中展示覆盖率、干扰错误、缺失信息处理、计数来源和证据位置。

## 7. 受控验收样例

| 案例 | 条件 | 预期 |
| --- | --- | --- |
| LCTX-01 | 4K/16K/64K 均在已验证范围，目标事实位置变化 | 各档使用同一基础题，按档独立评分 |
| LCTX-02 | 64K 超出 #38 已验证范围 | 64K 未测，不计 0 分，不触发容量探测 |
| LCTX-03 | 最高档成功但没有失败边界 | 只报告最高已验证档，不写最大上下文 |
| LCTX-04 | 代理按字节限制拒绝长请求 | 标记环境异常，不归因长材料能力 |
| LCTX-05 | 材料缺少答案关系 | 正确回答未知/无法确定；编造为有效错误 |
| LCTX-06 | 同名对象和相似干扰 | 关系串值可定位，干扰错误单独统计 |

## 8. 验收标准

| AC | 检查 | 预期 |
| --- | --- | --- |
| AC-01 | 统计基础题和长度条件 | 40 个基础题、五类各 8 题，最多 120 次观察，重复测量不冒充独立题 |
| AC-02 | 核对材料和位置哈希 | 同题跨档只改变长度/干扰位置，事实和答案保持固定 |
| AC-03 | 核对 #38 边界交接 | 超出可靠输入范围的档位不发送、不计 0 分、不改写容量结论 |
| AC-04 | LCTX-03/LCTX-04 | 最高成功档、代理限制和容量上限不混淆 |
| AC-05 | LCTX-05/LCTX-06 | 缺失信息、编造、对象串值和干扰误用可独立诊断 |
| AC-06 | 评分和证据审查 | 各档覆盖、计数来源、原始输出、复核/重试和限制可追溯 |

本设计完成后仍需由 #26 接入正式题库和评分器；它不代表任何真实模型已完成长材料测量。
