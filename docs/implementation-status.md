## 本轮修复

1. 缓存原先只校验内容，没有校验执行权限；现在缺少执行权限也会重新释放，拒绝将组件根符号链接视为有效缓存。
2. 菜单/快捷键退出原先跳过窗口关闭的确认框；现在共用确认流程，避免重复确认，确认后等待保存与子进程清理。
3. GUI 原先忽略报告阶段错误，部分错误又会被刷新覆盖；现在保留错误，连接失败不再展示 Electron 内部 IPC 前缀。
4. 重测连接检查期间原先会将旧结果显示为“准备检测 100%”；现在先保留上次完成页并禁用操作，收到新检测事件后才切换为新编号和新进度。
5. 正式报告下载状态不再残留“示例记录”，移除重复打印监听，避免打印后丢失原筛选状态。

保留的 HTML 报告仅同步了最终下载提示文案和打印监听修复；检测数据、JSON、ZIP 和原始证据未改动。
