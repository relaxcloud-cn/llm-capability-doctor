### 独立验收矩阵（本轮新增准确性门槛）

`tests/fixtures/acceptance-matrix.json` 预先固定 50 个场景的预期判定（先标注、后实现，不为迁就程序输出改答案），`tests/acceptance_matrix.rs` 对每个场景在 Chat Completions 与 Responses 两种协议下分别执行真实本地 HTTP 传输或独立构造的任务证据，共 **100 项判定**。首轮矩阵暴露了 18 个不一致并已全部修复：

- 工具检测原来硬编码两轮往返，合法的串行/追加/重复查询被误判失败；现改为最多 32 轮交互循环，按实际消息核对每次调用与回传。
- 观察层的通过/失败标签曾直接决定裁决；现标签不替代证据，裁决一律由评估器从原始证据重算（`Claim.validity` 显式化；`pass_summary` 改为注册表静态文本）。
