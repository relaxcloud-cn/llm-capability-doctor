## 首次完整核心链路实测

真实模型请求名称 `cybersec-1.0`，协议 Chat Completions，服务返回型号字段为 `deepseek-v4-flash`。不据此断言底层模型身份。凭据仅从仓库外的本机配置读取。

[机器结果](acceptance/2026-10-10-full-chat/result.json)、[实际报告](acceptance/2026-10-10-full-chat/report.html)、[完整证据 ZIP](acceptance/2026-10-10-full-chat/records.zip)、[桌面截图](acceptance/real-report-1280.jpg)。开发命令已实际执行全部 8 项和规定三批 6 次 OMP，用时 114.418 秒：

- 6 项通过；原生结构化输出返回无效 JSON，保留为失败。
- 并发校准缺少实际交付输出的准确计量，保持未确认；没有伪造 4 并发通过或性能数据。
- 已测下限 393,216 tokens。服务错误给出的声明值相同，但失败只给出输入长度下界，因此没有将其冒充精确实测最大值。
- ZIP 核对：314 个文件，64 个请求重放脚本，6 份任务结果，编号匹配，未包含配置目录或 API Key。
- 规则生成报告时不读取模型凭据或调用模型。

此外 [六次独立任务证据](acceptance/2026-10-10-chat/summary.json) 已逐项用独立 Python 比较实际文件与受保护源快照，核对 12/13 条记录和正常结束。加强故障恢复因果检查后单独复测也通过，避免将此前已排队调用的完成误认为收到错误后新发起的行动。

## 已修复的实际误判与保留的失败

[工具答复样本](../tests/fixtures/tool-answer-fenced.json) 的记录数据正确，仅有 Markdown 包装。共用会话内容解析接受一个明确 JSON 代码块及说明文字，原生约束和磁盘 JSON 仍严格校验。[原生格式失败样本](../tests/fixtures/native-schema-invalid.json) 虽 HTTP 200 正常结束，但正文损坏，不能解析成 JSON；没有通过清理损坏前缀使其变成“通过”。

当前 21 项单元测试和 2 项真实响应回放测试通过。测试通过并不证明整体产品准确性已验收。详细字段比较不依赖模型宣称、关键词评分、定制答案或另一个评分模型。
