# 工具选择与参数填写：题库与评分设计

父任务：#17。类型：设计。版本：0.1，2026-09-09。

本项设计标准任务中的工具选择和业务参数填写成绩。只写设计，不执行工具、不调用模型、不开发评分器。

## 客户问题与边界

#16 已区分“会生成工具调用”和“工具控制参数生效”。本项进一步问：面对任务，是否选对工具、填对业务参数，并知道什么时候不应调用？不引入完整 Agent 环境、跨服务执行或真实业务操作。

## 首版子项与题量方案

| 子项           | 题型方向                                                             | 初始设计数量 |
| -------------- | -------------------------------------------------------------------- | ------------ |
| 工具选择       | 多个候选工具含相近干扰项，从任务目标判断。                           | 8 题         |
| 业务参数填写   | 从明确业务语境获得日期、对象、单位等参数；不再直接给出全部调用答案。 | 8 题         |
| 多目标调用组合 | 判断需要哪些调用及对应参数，允许题目预先定义的等效组合。             | 8 题         |
| 不应调用       | 4 题无需工具、4 题没有匹配工具，不因“没调用”直接扣分。               | 8 题         |
| 必需信息不足   | 缺少必需业务信息时请求澄清，不编造参数完成调用。                     | 8 题         |

共 40 题，每题 1 份计分回答。调用方案按集合或有序序列评分由题目提前固定。工具本体可为纯描述的虚构接口，不要求执行。

## 来源与选用

参考 [BFCL 固定快照](https://github.com/ShishirPatil/gorilla/tree/6ea57973c7a6097fd7c5915698c54c17c5b1b6c8/berkeley-function-call-leaderboard) 的工具/参数匹配、相关性及答案校验方法。已读取 README 和类别说明。

优先研究单轮和相关性子集，不引入 web search、memory 或多轮执行环境。不能把 BFCL `multiple` 等标签按字面直接当成本产品类别，具体数据定义须逐项映射。原版抽样、中文改编和原创补充都单独标识，不宣称完整 BFCL 成绩。

README 的项目声明不能替代最终所选数据文件的使用条件核对；在具体样本选定前不将数据整体随产品分发。工具缺失、缺参等语境如需参考多轮任务，应明确属于抽取/改编，不把任务变换隐藏在原榜单名下。

## 评分设计

主指标为任务决策完整正确数 / 已评分有效题数；必须同时满足该题要求的调用/不调用决定、工具集合、业务参数及约束。诊断项分别显示选错工具、参数错误、遗漏调用、多余调用、不应调用却调用，以及缺参时编造。

正确不调用是正向答案，不等于模型拒绝测试。预先列出允许的不调用理由、澄清问题要点与等效工具组合；不以工具名字符串完全相同作为所有题目的唯一正确性标准。

不使用 `tool_choice` 强制指定答案或 required 来完成应由模型自行决定的题目。对于无工具能力的服务，不用伪造调用给它补测；能力前提与该类未覆盖原因单列，不把整类缺测展示为 0 分或全量成绩。

## 说明样例（原创，非正式题库与实测）

提供 `lookup_order(order_id)` 和 `cancel_order(order_id)`。任务：“看看 A123 是否已发货，不要取消订单。”

| 回答                             | 预期解释                                   |
| -------------------------------- | ------------------------------------------ |
| 调用 `lookup_order`，参数为 A123 | 正确选择和参数。                           |
| 调用 `cancel_order`              | 工具选择错误，即使调用结构合法也不得通过。 |
| 调用查询工具但订单号为 A132      | 业务参数错误。                             |
| 没有给订单号时追问订单号         | 在缺参变体中是正确答案，不视为任务失败。   |
| 没有给订单号却编造 A123          | 缺参时无依据填写。                         |
