# 长输入与长输出性能：材料、输出及历史长度设计

父任务：#18。模块：模型性能实测。状态：设计草案，2026-09-09。本轮不实现、不实测、不开展验收。

## 目标与范围

分别观察材料、输出和历史变长后，首响、完整耗时、正文速率、停顿和异常如何变化。不测长材料理解，不重测最大上下文，不搜最长输出，也不恢复已撤销的 P01 输出控制参数专项。

## 客户结果

| 变化方向     | 主要对照                                               |
| ------------ | ------------------------------------------------------ |
| 材料输入变长 | 输出目标保持一致，展示首响及总耗时变化。               |
| 输出变长     | 输入保持一致，展示实际长度、正文速率、间隔及总耗时。   |
| 历史变长     | 同一当前问题，展示多消息组织与等总长度平铺材料的差异。 |

目标长度、实际长度和入组数量同屏。单纯输出更长导致耗时增加，不自动标性能失败。

## 固定设计

| 组     | 输入条件                                                     | 目标输出         | 正式样本                      |
| ------ | ------------------------------------------------------------ | ---------------- | ----------------------------- |
| 长材料 | 2048、8192、32768 token                                      | 256 token        | 每档 15 次                    |
| 长输出 | 512 token                                                    | 1024、2048 token | 每档 15 次                    |
| 历史   | 4、16、32 条交替历史消息，每条约 128 token，另加固定当前问题 | 256 token        | 每档历史/等总长度平铺各 15 次 |

全部采用流式、单并发，各配置预热 3 次；单请求超时 120 s，每配置正式组最多 30 分钟，不自动重试。相同已执行条件可以复用原证据，但不能算新增样本。

输入只采用 #16 已取得可靠接受证据的范围，不能核实的档位标记前提不足，不在这里试探容量。无需精确最大上下文数字才能测试已有可靠下界中的档位。

输出长度是有限任务目标；达到 80%–120% 作为目标档的入组条件，正常短答仍保留在全请求视图。没有最长输出结论时，不以此阻止有限任务设计，也不声称该有限长度就是最大值。

历史不是 Agent 连续执行。材料和目标任务保持相同，平铺组与历史组的总输入长度应匹配；记录消息封装开销。不能只比较“短平铺”与“长历史”后把全部差异归因于历史组织。

## 设计反例

| 观察                               | 预期表达                               |
| ---------------------------------- | -------------------------------------- |
| 无法确认 32768 输入处于已验证范围  | 该档不执行，不降到 8192 后仍叫 32768。 |
| 目标 2048，实际 100 token          | 长度未达标，保留记录，不计目标档性能。 |
| 长输出总耗时更大，单位正文速率相同 | 展示长度影响，不直接标性能退化。       |
| 历史组输入总量多于平铺组           | 标明不可比，不归因于消息组织。         |
