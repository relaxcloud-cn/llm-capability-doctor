# AgentCheck 使用说明

拿到适合你电脑的程序后，解压即可使用，不需要另外安装软件。

## 1. 准备三项信息

向模型服务方获取：**完整接口地址、模型名称、密钥（API Key）**。

## 2. 一条命令开始检测

打开终端，进入解压后的程序文件夹。把下面的地址、模型名称和密钥换成自己的，再运行：

```sh
MODEL_API_KEY='你的密钥' ./agent-check --url 'https://model.example.com/v1/chat/completions' --model '你的模型名称' --report-dir ./results
```

以上命令适用于 Mac 和 Linux。程序会先检查连接，连接成功后自动检测；有桌面界面时会自动打开，否则在终端显示进度。等待提示检测结束，不要提前关闭窗口。

**注意：检测会产生模型使用量；命令中的密钥可能保留在终端历史中，不要截图或转发。**

## 3. 查看报告

检测结束后，打开程序文件夹中的 `results`，进入本次检测的文件夹，双击 **`report.html`**。如果在服务器上运行，先把该文件夹下载到电脑再打开。

报告会说明哪些项目通过、哪些需要处理；“未确认”表示这次没有测出可靠结论，不等于模型不行。需要 PDF 时，在报告中点击“打印 / 保存 PDF”。

## 遇到问题

- **提示 `Permission denied`**：先运行 `chmod +x ./agent-check`，再执行上面的检测命令。
- **连接不上或出现报错**：核对地址、模型名和密钥；仍有问题，把不含密钥的错误截图发给交付人员。
- **想中途停止**：界面中点击“停止检测”，或在终端按 `Ctrl+C`，等待保存完成。

再次运行同一命令即可重新检测，旧报告会保留。
