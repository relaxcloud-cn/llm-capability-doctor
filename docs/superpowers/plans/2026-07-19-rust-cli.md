# Native Rust Model Capability Doctor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a native, single-binary Rust CLI that reproduces all 62 Shell
collector checks and emits report-compatible evidence-v1 logs without invoking
`bash` or `curl`.

**Architecture:** A small entry point drives a typed catalog and runner. Protocol
adapters construct JSON requests, a native Reqwest client captures raw response
evidence and timings, focused check modules describe the 62 request flows, and a
serialized audit writer preserves the current log contract.

**Tech Stack:** Rust 2024 edition, Clap 4.6, Tokio 1.53, Reqwest 0.13 with
Rustls/system proxy support, Serde/serde_json, Chrono, Tokio-util cancellation,
Httpmock and Assert_cmd for integration tests, Python 3 for parser compatibility.
