# 大模型能力诊断工具项目介绍 PPT 设计

## 目标与受众

本材料面向 FDE 交付人员，用于内部培训、客户现场协作和模型接入前沟通。材料需要回答三个问题：为什么开发这款工具、工具检测哪些能力、交付人员如何从准备程序到取得结果 Markdown。

## 页面结构

1. 封面：大模型能力诊断工具，副标题为“模型接入前的一键能力核验”。
2. 开发背景：说明模型连接信息和能力表现经常对不齐，口头确认无法替代真实运行验证，问题后置会造成部署返工。
3. 工具价值：突出“一个工具、一个命令、一次执行、直接结论”，把 FDE 与客户的反复确认变成标准化检测结果。
4. 检测范围：把 46 项检测归并为 8 类，即接口与协议、结构化结果、上下文、指令与文本、Thinking 与推理、工具调用、性能与稳定性、护栏与词汇。
5. 使用准备：先确认客户操作系统和 CPU 架构，再选择 Windows、Linux 或 macOS 对应的 x86_64 或 ARM 程序。
6. 信息准备：把执行程序传入客户环境，并获取模型 URL、API Key、模型名称三项连接信息。
7. 命令执行：强调必须进入执行程序所在目录，分别给出 Linux/macOS 和 Windows PowerShell 的命令拼接示意。
8. 结果交付：说明执行完成后获得结果 Markdown，用于能力结论、问题定位、客户确认和交付留档。

## 视觉设计

每页使用 Codex Imagen 直接生成 16:9 简体中文整页图片。视觉采用浅灰背景、深藏蓝模块、深红标题与强调、克制金色分隔线，不使用 Logo、水印、角标或营销式装饰。页面以左右对照、八类能力矩阵、五步时间线和命令终端场景为主，每页只表达一个观点。

## 讲稿备注

每页写入中文演讲备注，补充页面未展开的客户价值、交付注意事项和讲解收束。备注不重复页面文字，并明确说明该工具用于模型接入前核验和双方结论对齐。

## 内容边界

- 页面只展示 8 个检测大类，不罗列全部 46 项。
- API Key 使用占位符或掩码，不展示真实凭据。
- 输出按已确认口径写为结果 Markdown。
- 不承诺模型质量分数，只陈述检测覆盖、执行事实和结论输出。

## 验收标准

- PPTX 共 8 页，比例为 16:9。
- 8 张页面主体图全部来自 Codex Imagen。
- 每页均包含中文讲稿备注。
- 命令参数覆盖模型 URL、API Key、模型名称，并标明工作目录要求。
- 最终逐页渲染检查，无严重文字错误、裁切、重叠或不可理解的流程。
