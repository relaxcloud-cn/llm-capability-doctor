# AgentCheck 桌面端与交互原型

macOS 原生 GUI，UI 以本目录的原型为准。桌面端由 Rust CLI 在有桌面环境时启动，负责配置确认、检测范围选择、真实检测进度、结果查看和报告导出；`--review-all` 和 `--self-test` 仍用于离线体验与状态验证。

## 启动

在当前目录运行 `./agent-check start`，或打开 `build/AgentCheck.app`。首次启动显示模型配置页；点击“使用示例配置”，再点击“连接服务”。

全页面评审可运行 `open -n build/AgentCheck.app --args --review-all`。新窗口预置两次演示记录，可以直接检查全部结果页面；该模式仅用内存，不改动已有配置和历史。

原型需要 Apple Silicon Mac、macOS 14 或更新版本；重新编译需要 Xcode Command Line Tools。使用 SwiftUI/AppKit 只是本轮原型选择，不代表正式版选型。

## 可交互范围

1. 模型配置、密码输入、输入校验、模拟连接成功、鉴权失败和超时。
2. 首页及报告复用“模型接入信息”摘要，可展开来源与响应名称。它不是独立检测项目；检测确认由用户选择另外五个模块，不预设正式默认组合。
3. 模型规格实测七类、模型能力跑分六类、模型性能实测五类、智能体实测八项、模型基线对比十四项。每页提供条件、结果、边界和样例证据。
4. 历史搜索、当前配置筛选、同条件记录并列、原配置结果回看和带证据的 JSON 导出。比较前核对范围、规则、样本、平台、参数、环境与基线快照。
5. 原生设置窗口和独立“演示模式”控制；空结果、未完成、环境失败、旧版记录均有独立表达。

## 本轮产品体验更新（2026-09-09 全面重做）

针对“看起来不像产品、第一眼看不到重点”的问题，本轮按“答案先行”重构了整个呈现层，数据层与状态测试不变。

1. **统一设计系统（`Sources/Theme.swift`）**：字号层级（结论 25pt 粗体、区块 16pt、正文 13pt、说明 11.5pt）、状态色语义（绿=通过、琥珀=受限、红=阻断、灰=未知，全部伴随图标与文字，色板经 CVD/对比度校验）、卡片栅格与 12pt 圆角。每个标签只用中文，不再中英混排。
2. **每页一个第一眼答案**：首页与结果页以大结论横幅（图标+结论+一句话解释+主行动）开场，随后是三张适用范围卡（已验证范围/使用限制/尚未覆盖）、“需要处理的问题”卡（可直达失败执行）和六个模块卡片。运行页用大号百分比与“正在测什么”的清单。
3. **首检引导**：无记录时首页直接回答“这个模型能不能胜任 Agent 任务？”，三步卡片（连接服务→选择检测→查看结论）+主按钮，产品开场即自我介绍。
4. **词汇收敛**：全文统一“检测”（运行态用“进行中/等待中/已完成”），结论词只用文档 4.1 的四种；内部代号（allinone、OhMyPi、样本集编号）从页面脚注移除，只在证据与导出层保留。
5. **图表规范**：性能图表统一细标记、圆角端点、直接标注数值；状态色只表达状态，不用于装饰。
6. **截图工具修复**：整窗 `cacheDisplay` 对超长滚动页会二次合成（旧版 result-inconclusive 等“缺模块”截图即此伪影），超长页改为视口级捕获，保证截图所见即所得。

## 数据边界

`--review-all`、截图和状态测试使用预设模拟数据。由 Rust CLI 通过 `--agentcheck-*` 参数启动的桌面会话，会再以子进程运行同一 CLI 的 `--no-gui --format json --progress-file` 流程；该路径调用真实模型服务，GUI 只展示统一报告，不重新定义模块结论。

真实检测仍然受发行包的协议、样本、环境和可靠性边界约束，不保证生产平台可用性。

按 `PRODUCT-DESIGN.md` v0.6 展示十个共享 Agent 样本。受限场景包含三十次初测和两次失败复核的虚构记录；执行只统计一次，不因关联多个检查项而重复累计。支持复现失败、偶发失败、待复核、严重权限问题和环境无效状态，但没有实际消耗测试预算。

模型基线对比的十四项均有左右局部结构样例，支持多条响应、流式阶段、可选字段差异、原始局部片段和三类空缺状态。参考快照采用产品文档已选版本，未重新执行官方规范验证。结构演示独立于 Agent 任务证据，不参与可用性结论；没有协议总分或兼容率。

规格、能力题目与性能负载均为演示选择，不是正式默认值。能力成绩呈现正确完成数，不擅自定义百分制、权重或合格线。

新版演示记录带 `presentationVersion: 3` 及测试条件。本轮只调整展示与交互，不升级证据版本。旧记录保留原始数据，不套用本版分类或证据，也不能与新版记录直接比较。评审窗口标题为“AgentCheck — 模型服务体检”。

API Key 仅在输入时存在于内存，模拟验证开始后清空，从不发送、持久化或导出；正式产品的密钥保存策略仍待设计。新配置地址禁止带有用户名、密码、查询参数和片段；旧记录显示与导出也会脱敏地址。

非敏感配置和模拟记录保存在 `~/Library/Application Support/AgentCheckPrototype/session.json`。再次打开会恢复配置；需要查看输入状态，可通过工作台的“更换模型”进入配置页。

## 验证

运行 `bash build.sh` 编译，再运行 `build/AgentCheck.app/Contents/MacOS/AgentCheck --self-test` 验证状态逻辑。

运行 `build/AgentCheck.app/Contents/MacOS/AgentCheck --capture build/screenshots-all` 自动生成各页面、七类规格、六类成绩、五类性能、十四项基线、弹窗、证据展开和异常状态截图，同时检查画面非空。截图模式使用临时内存数据，窗口留在后台，不污染本机历史。窗口截图覆盖标准尺寸与窄窗口，但不等于已经完成真实客户可用性测试。

本轮状态测试覆盖首页直达失败执行、历史证据归属，以及编辑配置时跳转的凭据清理。截图覆盖 94 个场景，关键页面已进行视觉检查。尝试原生辅助功能点击自动化时，测试进程未能读取 SwiftUI 控件树，因此移除了未通过的入口，不将状态测试或截图冒充真实点击验收。

当前启动脚本提供原生 GUI 构建入口。macOS 发行包包含 `AgentCheck.app`；无桌面环境、SSH、CI 或显式 `--no-gui` 时，Rust CLI 继续提供无人值守流程。其他桌面平台需要各自的原生 GUI 构建目标，当前明确回退到 CLI。
